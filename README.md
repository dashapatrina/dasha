# Разработка рекуррентной нейронной сети на базе TensorFlow Python для выявления токсичности в текстах

**Тип сети:** Bidirectional LSTM (BiLSTM)  
**Фреймворк:** TensorFlow / Keras  

---

## Введение

### Актуальность работы

Проблема токсичности в онлайн-коммуникациях является критической для современных цифровых платформ. По данным исследований, до 40% пользователей социальных сетей сталкиваются с оскорбительным контентом.

**Автоматизированная модерация позволяет:**
- Обрабатывать миллионы сообщений в реальном времени
- Снизить нагрузку на модераторов на 80-90%
- Обеспечить объективную оценку токсичности
- Работать круглосуточно без перерывов

**Результаты проекта:**
- Accuracy: 95.7%
- ROC AUC: 98.2%
- Компактная модель: 1.5M параметров

### 2.5. Реализованные алгоритмы

**1. Keras Tokenizer**  
Преобразование текста в последовательность индексов с обработкой OOV токенов.

**2. Padding/Truncating**  
Приведение всех последовательностей к единой длине (200 токенов).

**3. LSTM Forward Pass**  
Рекуррентная обработка с управляемым забыванием через forget gate, input gate, output gate.

**4. Bidirectional Processing**  
Обработка последовательности в прямом и обратном направлениях для учёта полного контекста.

**5. Adam Optimization**  
Адаптивный градиентный спуск с momentum (β1=0.9, β2=0.999, lr=0.001).

### 2.8. Использование модели

```python
import tensorflow as tf
from tensorflow.keras.preprocessing.sequence import pad_sequences
from tensorflow.keras.preprocessing.text import tokenizer_from_json
import json

# Загрузка модели и токенизатора
model = tf.keras.models.load_model('toxicity_bilstm_model.keras')
with open('tokenizer.json', 'r') as f:
    tokenizer = tokenizer_from_json(f.read())

# Предсказание
def predict_toxicity(text):
    seq = tokenizer.texts_to_sequences([text])
    pad = pad_sequences(seq, maxlen=200, padding='post')
    prob = float(model.predict(pad)[0][0])
    return prob

# Пример
text = "You are stupid!"
toxicity = predict_toxicity(text)
print(f"Toxicity: {toxicity:.4f}")
```
